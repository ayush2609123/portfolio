Production-grade full-stack developer portfolio showcasing real projects and MAANG-level skills.

## 🚀 Quick Deploy (2 Minutes)

### Option 1: Deploy on Vercel (Easiest)

1. **Push to GitHub**
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio"
   git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
   git push -u origin main
   ```

2. **Deploy on Vercel**
   - Go to https://vercel.com
   - Click "Sign up" (use GitHub)
   - Click "Import Project"
   - Select this repository
   - Click "Deploy"
   - Done! Your URL will be ready in 1-2 minutes

**Your URL:** `https://portfolio-[random].vercel.app`

### Option 2: Deploy on Netlify

1. Push to GitHub (same as above)
2. Go to https://netlify.com
3. Click "New site from Git"
4. Select your GitHub repo
5. Click "Deploy"

**Your URL:** `https://[name].netlify.app`

### Option 3: Custom Domain (Optional)

After deploying on Vercel/Netlify:
1. Buy domain from Namecheap/GoDaddy (~₹300-500/year)
2. Add domain in Vercel Settings → Domains
3. Point nameservers to Vercel
4. **Your Custom URL:** `https://ayushkushwaha.dev` (or your choice)

## 🆘 Troubleshooting

**Issue:** Node modules error
```bash
rm -rf node_modules
npm install
```

**Issue:** Port 3000 already in use
```bash
npm start -- --port 3001
```

**Issue:** Tailwind not working
- Make sure you're using React Scripts 5.0+
- Check that `lucide-react` is installed
